# モンバス パッシブ計算アプリ

モンスターのパッシブ値を比較して、パーティーを作成するアプリです。

## 起動方法

Node.js 18 以降が必要です。静的ファイルのホスティングでは API が動作しないため、Node.js サーバーとして起動してください。

```sh
export MONSTER_ADMIN_TOKEN="$(node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))")"
node server.js
```

ブラウザーで `http://localhost:3000` を開きます。サーバーをインターネットに公開する場合は HTTPS を使用してください。

## データ共有と保存

- モンスター一覧はサーバーの `/api/monsters` から取得し、追加・編集・削除はサーバーへ保存されます。
- 初回起動時は `monster.js` の既存データが使用され、最初の変更時にデータファイルが作成されます。
- 保存先は `MONSTER_DATA_FILE` で指定できます。既定値は `data/monsters.json` です。ホスティング環境では、再起動後も残る永続ディスクを指定してください。
- モンスターの閲覧は公開されます。変更には `MONSTER_ADMIN_TOKEN` が必要で、管理画面で入力するとそのタブの間だけ保存されます。
- パーティー構成は引き続きブラウザーの `localStorage` に保存され、ユーザー間では共有されません。
- 既存ブラウザーの `localStorage` にだけ保存されているモンスター変更は、自動ではサーバーに移行されません。

## 運用上の注意

公開前に十分に長い `MONSTER_ADMIN_TOKEN` を設定し、秘密として管理してください。Node.js サーバーと永続ディスクを提供するホスティング環境が必要です。GitHub Pages などの静的ホスティングのみでは共有保存できません。
